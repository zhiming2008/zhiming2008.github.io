孟德尔遗传实验和摩尔斯果蝇实验

1.孟德尔——不想种豌豆的修道士不是好蜜蜂爱好者

1.1为什么是豌豆

豌豆的优点:

  1. 是自花传粉植物：这意味着在自然状态下，豌豆通常都是纯种的，避免外来花粉的干扰 。
  2. 容易进行人工杂交：虽然豌豆是自花传粉，但孟德尔可以通过人工去除雄蕊（去雄）然后将其他植株的花粉涂撒到雌蕊上的方式进行异花传粉（杂交）。
  3. 具有易于区分的相对性状：豌豆植株有很多容易区分的性状，比如高茎和矮茎、圆粒和皱粒、红色花和白色花等等 。一种生物同一种性状的不同表现类型就叫作相对性状 。这些性状能够稳定地遗传给后代。

据载孟德尔曾在修道院饲养动物，使用定制蜂箱养殖蜜蜂。除摩拉维亚养蜂协会报告中的零星记载外，其养蜂研究成果未存世。已知他饲养的塞浦路斯蜂和卡尼鄂拉蜂攻击性强，引发其他修士和访客不满，终被要求清除。孟德尔却视蜜蜂为“最亲爱的小动物”。

孟德尔为了验证豌豆中发现的遗传规律是否适用于性状更复杂的植物，以山柳菊属（Hieracium）进行实验，并发表相关报告。该属植物因多样性备受当时科学家关注。然其实验结果与豌豆迥异：子一代变异显著，多数后代与母本相同。
直至十九世纪末，学界才认识到多数山柳菊属植物通过无性生殖产生种子。

1.2分离定律

孟德尔首先研究的是一对相对性状的遗传。他选择了一对纯种的豌豆进行杂交，他发现，无论是用高茎豌豆作母本还是父本，杂交后产生的子一代（F1F_1F1​）都只表现出高茎的性状 。高茎豌豆和矮茎豌豆杂交后，子代全部是高茎的，矮茎性状似乎“消失”了。

这与当时流行的“融合遗传”观点是不同的。融合遗传认为父母双方的遗传物质会在子代体内混合，产生介于双亲之间的性状。但孟德尔的实验结果却表明，矮茎性状并没有消失，只是在F₁中没有表现出来。

孟德尔把在F1F_1F1​中显现出来的性状（比如高茎）称为显性性状（dominant trait），而把未显现出来的性状（比如矮茎）称为隐性性状（recessive trait）。

F1F_1F1​自交后会发生什么呢？孟德尔带着疑惑，让F1F_1F1​（全是高茎）进行自交，结果在第二代（F2F_2F2​）植株中，他惊奇地发现，不仅有高茎的，矮茎性状又重新出现了！而且，他统计了F2F_2F2​中高茎和矮茎的数量，发现高茎与矮茎的性状分离比接近3:1。

这种在杂种后代中同时出现显性性状和隐性性状的现象，被称为性状分离。

这个3:13:13:1的比例是不是很神奇？它说明了什么呢？

8年时间里，孟德尔在前前后后测试了20000多株豌豆后，孟德尔终于总结出杂交性状在后代系列的分离比是3:13:13:1。

孟德尔在观察和统计分析的基础上，提出了一个假说，也就是分离定律：

  1. 遗传因子决定性状：生物的性状是由“遗传因子”决定的，这些因子就像一个个独立的颗粒，它们既不会相互融合，也不会在传递中消失。每个因子决定一种特定的性状。决定显性性状的因子叫做显性遗传因子（用大写字母如D表示），决定隐性性状的因子叫做隐性遗传因子（用小写字母如d表示） 。
  2. 遗传因子成对存在：在生物的体细胞中，遗传因子是成对存在的。比如纯种高茎豌豆的体细胞中有成对的DD，纯种矮茎豌豆的体细胞中有成对的dd。像DD或dd这样遗传因子组成相同的个体，被称为纯合子。而F1F_1F1​由于杂交而来，它们表现显性性状，但又含有隐性遗传因子，所以它们的遗传因子组成是Dd。像Dd这样遗传因子组成不同的个体，被称为杂合子 。
  3. 遗传因子的分离：在生物体形成生殖细胞（配子）时，成对的遗传因子会彼此分离，分别进入不同的配子中。所以，每个配子中只含有每对遗传因子中的一个 。例如，DD的纯合子只能产生含D的配子，dd的纯合子只能产生含d的配子。而Dd的杂合子则会产生两种配子：含D的配子和含d的配子，它们的比例是1:11:11:1。
  4. 受精时的随机结合：受精时，雌雄配子的结合是随机的 。这意味着，含D的配子既可能与含D的配子结合，也可能与含d的配子结合。

孟德尔巧妙地设计了测交(test cross)实验,让F1F_1F1​与隐性纯合子杂交。以F1F_1F1​高茎豌豆(Dd)与隐性纯合子矮茎豌豆(dd)杂交为例,孟德尔根据假说,推出测交后代中高茎与矮茎植株的数量比应为1:11:11:1，孟德尔正是通过测交实验来验证他的假说的。

1.3自由组合定律

在理解了单一性状的遗传规律后，孟德尔没有止步于此，他又开始思考：如果同时考虑两种或多种性状的遗传，它们之间会相互影响吗？于是，他设计了研究两对相对性状的杂交实验。

孟德尔选择的亲本是：纯种黄色圆粒豌豆和纯种绿色皱粒豌豆

他将它们进行杂交（PPP代），结果发现子一代（F1F_1F1​）全部都是黄色圆粒的。这再次证明了黄色和圆粒是显性性状，而绿色和皱粒是隐性性状。

接下来，他让F1F_1F1​的黄色圆粒豌豆进行自交。孟德尔发现，在子二代（F2F_2F2​）中，除了亲本原有的性状组合——黄色圆粒和绿色皱粒之外，还出现了两种新的性状组合——绿色圆粒和黄色皱粒 。

他同样对F₂的性状进行了数量统计，结果发现，黄色圆粒、绿色圆粒、黄色皱粒和绿色皱粒的数量比大约是 9:3:3:19:3:3:19:3:3:1 。

孟德尔对这个结果进行了更深入的分析：
他将两对性状分开来看，只看种子形状（圆粒和皱粒），F2F_2F2​中圆粒和皱粒的数量比接近3:13:13:1 。

同样地，只看子叶颜色（黄色和绿色），F2F_2F2​中黄色和绿色的数量比也接近3:13:13:1 。

这表明，即使在两对性状的杂交中，每一对相对性状的遗传仍然遵循着分离定律，而且它们之间互不干扰 。

孟德尔对此作出了如下解释：
在F1F_1F1​产生配子时，每对遗传因子彼此分离，同时，不同对的遗传因子可以自由组合。

这种不同对遗传因子自由组合的现象，就是自由组合定律的核心。

1.4被埋没的伟大发现

1865年孟德尔满怀期待的在当地的自然科学学会上宣读自己的论文——“植物杂交试验”。但结果却让他大失所望，所有人都觉得他说得好像有点道理，但是又觉得不明所以。他的研究成功没有掀起一丝波澜。

孟德尔不愿放弃自己8年来的艰辛，论文发表后，他立刻把40份抽印本寄给各地著名的科学家。但他寄出去的论文要么没有回音，要么只有质疑和讽刺。没有人相信一个普通牧师的研究成果。

这一系列打击并没有击垮孟德尔，他很快就调整好心态继续论证自己的成果，不只是种植豌豆，还做了紫罗兰、茯苓、玉米和紫茉莉等植物甚至还做了动物实验，发现都符合所得出的结论。

1869年他又发表第二篇论文“动植物遗传之研究”。在两篇论文中，孟德尔提出了遗传单元（现称基因）显性性状，隐性性状等重要概念，阐明其遗传规律。

1859年，达尔文发表《物种起源》，创立进化论，为生物科学的大厦立下了一个支柱，但是这座大厦仍然摇摇欲坠。达尔文进化论的核心是自然选择学说，但是他找不到一个合理的遗传机理来解释自然选择，无法说明变异是如何产生，而优势变异又如何能够保存下去，达尔文为此苦恼终生。他在1872年如此写道：遗传的定律绝大部分依旧未知，没有人能够说明在同一物种的不同个体中的相同特性，或在不同物种中的相同特性，为什么有时候能够遗传，而有时候不能；为什么孩子能恢复其祖父母甚至更遥远的祖先的某项特征。

达尔文不知道的是，这些问题已经被奥地利修道院的一个业余生物学家孟德尔通过豌豆杂交试验解决了。据说孟德尔给达尔文寄过自己的论文，但是达尔文并未打开看。生物科学大厦的另一个支柱早就立好，但是孟德尔在1865年发表的成果被科学界忽略了。

孟德尔始终相信“我的时代会到来”。只是他不再试图去说服那些专家们，甘愿忍受孤独。1884年，孟德尔因病去世。

1901年，孟德尔定律再度被人发现。此时孟德尔已经去世16年，孟德尔定律的再发现却足以照亮新的世纪。他不再是当初默默无闻的小人物，成为了“超越时代的天才”。

2.摩尔根果蝇实验

2.1为什么是果蝇

在摩尔根之前，萨顿通过研究蝗虫细胞，发现孟德尔遗传因子（等位基因）的分离与减数分裂中同源染色体的分离过程非常相似，提出了“基因是由染色体携带着从亲代传递给下一代的”假说，也就是“基因在染色体上”的假说 。

然而，萨顿的假说缺少直接的实验证据 。最终，摩尔根将目光投向了一种常见的昆虫——果蝇。

果蝇主要有以下几个重要的优势：

  1. 易于饲养：果蝇对生活环境要求不高，容易在实验室中进行大规模饲养，这为实验提供了充足的材料 。
  2. 繁殖速度快：果蝇的世代周期非常短，在室温下大约10多天就能繁殖一代 。这意味着科学家可以在短时间内观察到多代遗传现象，大大加快了研究进程。
  3. 繁殖数量多：一只雌果蝇一生能产生几百个后代 。大量的后代样本有助于进行统计分析，发现遗传规律。
  4. 染色体数目少，相对性状明显：果蝇有4对染色体，其中3对是常染色体，1对是性染色体。同时，果蝇还有许多容易区分的相对性状（比如红眼和白眼，黄身和正常体色等），这使得遗传实验结果的判断更为直观 。

2.2摩尔根果蝇杂交实验过程与结果分析

摩尔根在一次偶然的机会中，发现了一只白眼雄果蝇。他很好奇白眼性状是如何遗传的，于是他设计了实验。

他的第一个实验是：用红眼雌果蝇和白眼雄果蝇进行杂交（亲代 P），F1F_1F1​（子一代）的果蝇是红眼。

而在F2F_2F2​代中，白眼果蝇全部是雄性 。

这个现象非常特殊，因为它表明白眼性状的遗传与性别是相关联的 。孟德尔的豌豆实验中，性状的遗传并没有表现出与性别有这种紧密的联系。

当时，一些生物学家已经在一些昆虫细胞中发现了性染色体。摩尔根也知道，果蝇的体细胞中有4对染色体，其中3对是常染色体，1对是性染色体。在雌果蝇中，这对性染色体是同型的，用 XX 表示；而在雄果蝇中，这对性染色体是异型的，用 XY 表示。

考虑到白眼的遗传与性别相关联，并且与X染色体的遗传有相似之处，摩尔根和他的同事们提出了一个设想：如果控制白眼的基因（用 w 表示）在 X 染色体上，而 Y 染色体上不含有它的等位基因，那么上述遗传现象就可以得到合理的解释。

提问：如果控制白眼的基因在Y染色体上，还能解释摩尔根的果蝇杂交实验结果吗?

回答：不行

  1. F1F_1F1​代的结果不符：如果白眼基因在Y染色体上，那么P代白眼雄果蝇 (XYwXY^wXYw) 与红眼雌果蝇 (XXXXXX) 杂交产生的F1代中，所有雄果蝇都会继承Y染色体，因此都将是白眼。然而，摩尔根实验的F1代是全部红眼。
  2. F2F_2F2​代的结果不符：在假设下，F2F_2F2​代的所有雄果蝇都将是白眼，所有雌果蝇都将是红眼。这与摩尔根实验中F2代出现红眼雄果蝇和红眼雌果蝇，且白眼只占1/4并全部为雄性的结果截然不同。
  3. 无法解释白眼雌果蝇的存在：如果白眼基因在Y染色体上，雌果蝇（XX）根本没有Y染色体，所以不可能表现出白眼性状。这一点是X连锁遗传的有力证据，而Y连锁遗传则无法解释。

结果：摩尔根从而用实验证据明确地将一个特定的基因与一条特定的染色体——X染色体联系起来，最终证明了基因位于染色体上。
